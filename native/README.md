# 南铂制作 · Mac / iPhone 试用版

## Mac 怎么用

打开「南铂制作.app」→ 添加主照片与拍摄前照片 → 开启「制作 Live」→ 调整画面 → 点「保存实况」。
首次保存时，系统会请求添加照片的权限。允许后，由应用直接写入苹果「照片」，无需下载、解压、选择配对文件或打开保存助手。普通 JPG / PNG 也保存到相册。照片仅在本机制作；若设备本身开启 iCloud 照片，苹果会按你的现有设置同步成品。

Mac 支持 macOS 13 及以上，Intel 和 Apple 芯片。当前为本机签名试用版，未做公开发行的 Apple 公证。

## iPhone 安装进度

iPhone 工程已通过 iOS SDK 编译，但不是已签名的安装包，也尚未进行真机相册保存验证。手机暂时不方便连接，因此保留工程，待连接后继续安装。

首次安装需在支持手机系统版本的 Xcode 中打开 `NanboStudio.xcodeproj`，选择连接并信任的 iPhone，在 Signing & Capabilities 中选自己的 Team，然后运行。当前 Mac 的 Xcode 为 15.2；如果它不支持手机的系统版本，需要合适版本的 Xcode/开发电脑。不要把未签名 app 压缩包当成可安装 IPA。

免费个人账户开发签名与长期分发不同；正式长期使用需另行确定签名/分发方式。本次未购买开发者会员、登录账户或创建证书。

## 已验证与待验证

- Mac universal 与 iPhone arm64 Release 构建通过。
- 本机 WKWebView 能离线加载真实制作页、读取合成测试图片、加载动画，并通过桥接发送 90 帧给原生编码器。
- 两种尺寸 1080×1920 / 1080×1440 的原生实况资源通过 Apple PHLivePhoto 只读识别；方向、90 帧、30fps、3秒、配对ID和最后一帧标记均检查。
- 原生导出/取消/失败、浏览器后备导出和原有核心的针对性测试通过。
- 自动测试没有读取或写入个人相册。Mac 的真实相册写入、iPhone 安装、相册写入和长按播放仍需用户设备验收。

## 使用限制

原生相册单次图片传输上限64MB；超大PNG会提示改用JPG。保存实况的最后写入相册阶段不可取消，以免误报结果。制作时请保持应用打开；不提供后台导出承诺。

## 源码结构

`Shared/` 是两端共用的Swift代码；`Web/` 是随应用打包的本地编辑器；`NanboStudio.xcodeproj` 可直接打开，不需要 npm 安装。应用不会把带相册能力的浏览器导航到远程页面。
