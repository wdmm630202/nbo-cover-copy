# 素人改造模板图层

透明 PNG 来自 Photoshop 中的「南铂素人改造计划 2.psd」。渐变于 2026-11-12 拆分，备注于 2026-11-13 从当前打开的原文档副本拆分；未保存或更改原 PSD。

| 文件 | PSD 中的可见图层 |
| --- | --- |
| `template-fixed.png` | 6000 × 8000，仅「固定元素」组，隐藏其独立备注文字，其余原有可见状态不变 |
| `template-gradient.png` | 仅「填色丨叠加颜色选色」图层，保留原有图层样式 |
| `template-note.png` | 「固定元素」内以 `*注：发现盗图` 开头的原文字图层（ID 281），按透明边界裁切为 1076 × 228 |

渲染顺序为照片、照片额外压暗与涂抹、模板渐变、固定元素、独立备注。模板渐变整体强度默认 100%，可独立调至 0–100%；切换照片和恢复当前照片默认均保留此整体设置，渐变旁的「复位」恢复 100%。预览与导出使用同一绘制函数。

渐变颜色默认黑色，可选白色、自定义颜色和预览吸色，与备注颜色独立。黑色直接使用原 PSD 图层；其它颜色只替换原渐变的 RGB，保持原有 alpha、形状及范围。`tint-mask.mjs` 用最大 2052 × 132 的临时画布分块调色，手机导出只处理当前可见的小块，不新增整幅原片尺寸的调色画布。强度复位与快捷值仅调整强度，保留已选渐变颜色。

备注位于原 6000 × 8000 画布的 `(104, 299)`，沿用 PSD 原字体栅格及 74.9019607843137% 图层透明度；仅通过 `source-in` 改变文字 RGB。默认黑色，提供黑白常用色、自定义系统选色及预览点击吸色。没有重打文字或重新生成图像。黑色备注与无备注固定层重新合成后，与拆分前固定模板在黑白底色上逐像素相同。独立备注的位图很小，手机仍直接使用原尺寸栅格。

`template-overlay.png` 是原来的合并模板，保留用于历史版本回退；当前界面加载拆开的三张 PNG。后续更新应继续从 PSD 原图层导出，保留画布、透明度、文字、Logo 和边框位置。

`template-fixed-mobile.png` 与 `template-gradient-mobile.png` 是上述整画布图层按相同比例以高质量重采样得到的 2160 × 2880 透明 PNG，仅供手机低内存预览。拆分备注时仅移除手机版固定层内的备注像素，其余像素保持不变。它们保留原图层的构图与透明度，不重新绘制文字或 Logo。更新原 PSD 图层时应同步重建手机版本；电脑和手机的原片像素导出均使用 6000 × 8000 原版图层；手机按小块绘制与编码，不降低输出尺寸。

渐变与备注吸色均为连续模式：点击预览即时应用取到的颜色并保持吸色状态，直到主动点击“完成吸色”、按 Esc、切换工具或改用预设/自定义选色；退出时保留最后选色。
