# 南铂工作台离线使用

网页在顶部显示「已可离线使用」后，可关闭页面、断网后重新打开原来的 cover.html 地址。缓存包含封面、素人改造、Live 程序、模板、卡片、配音和本地实况保存助手；不缓存用户导入的照片或导出的成品。

安装只有在所有资源下载完成并通过 SHA-256 校验后才成功；失败不会留下可激活的半套程序。新版本不会强制接管正在编辑的页面，点击「更新工作台」即可切换；若旧缓存阻止更新，可打开同目录的 update.html。更新后需重新选择照片，已下载图片与保存的设置不变。此缓存仅服务程序资源白名单，不拦截文案服务或客户照片。

浏览器可能清理网站数据，因此请同时保存本地文件：

- 「南铂素人改造离线版.html」：内嵌原 PSD 导出的模板、样式和程序。双击即用，无需 Python、服务器或首次联网。成品走浏览器下载；在线版仍保留桌面保存窗口。
- 「南铂制作台离线版.zip」：解压后包含完整封面、素人改造、Live 和使用说明。双击「启动制作台.command」使用本机 Python 3 启动；仅监听 127.0.0.1，所有程序资源均在包内。不依赖公网。若未安装 Python，可直接使用包内的单 HTML 素人改造版。

智能文案等联网服务仍需要网络；所有导入照片均由使用者本机选择。离线不改变图像质量、命名、渐变或导出设置。网页和本地版仍受可用内存、磁盘空间及浏览器能力限制，不能承诺设备故障、文件被删除或浏览器数据被清除时继续运行。

构建：`pnpm run build:cover-core` 会生成服务工作线程、独立 HTML 和完整 ZIP。独立 HTML 与 ZIP 是构建产物，由 Pages CI 发布，同时复制至 outputs；不得把客户照片放入构建目录。
