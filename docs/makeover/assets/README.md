# 素人改造模板图层

两张透明 PNG 来自 Photoshop 中的「南铂素人改造计划 2.psd」当前编辑版本（2026-11-12），画布均为 6000 × 8000 像素。导出时使用文档副本，原 PSD 保持原样。

| 文件 | PSD 中的可见图层 |
| --- | --- |
| `template-fixed.png` | 仅「固定元素」组，保留组内原有可见状态 |
| `template-gradient.png` | 仅「填色丨叠加颜色选色」图层，保留原有图层样式 |

渲染顺序为照片、照片额外压暗与涂抹、模板渐变、固定元素。模板渐变整体强度默认 100%，可独立调至 0–100%；切换照片和恢复当前照片默认均保留此整体设置，渐变旁的「复位」恢复 100%。预览与导出使用同一绘制函数。

`template-overlay.png` 是原来的合并模板，保留用于历史版本回退；当前界面加载拆开的两张 PNG。后续更新应继续从 PSD 原图层导出，保留画布、透明度、文字、Logo 和边框位置。

`template-fixed-mobile.png` 与 `template-gradient-mobile.png` 是上述两张图层按相同比例以高质量重采样得到的 2160 × 2880 透明 PNG，仅供手机低内存预览。它们保留原图层的构图与透明度，不重新绘制文字或 Logo。更新原 PSD 图层时应同步重建手机版本；电脑和手机的原片像素导出均使用 6000 × 8000 原版图层；手机按小块绘制与编码，不降低输出尺寸。
